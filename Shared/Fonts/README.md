# ipa+

A subsetted phonetic font bundled with ipa+ keyboard. The family name is **ipa+**;
the internal PostScript name is `IPAPlus-Regular`.

[Download TTF](https://github.com/ghehyoein/IPAkeyboardios/releases/latest/download/ipa-plus.ttf)
· [Download with licenses and coverage report](https://github.com/ghehyoein/IPAkeyboardios/releases/latest/download/ipa-plus-font.zip)

The font covers the app's current input inventory, including its 51 supplementary
modifier letters. Some rare Unifont-derived glyphs retain pixel-shaped outlines.
Other apps must select this font themselves; bundling it does not replace iOS fonts.
