## Project contributions

Contributions by **ghehyoein** cover **199 character glyphs**:

- **48 newly constructed vector glyphs**, including the twelve latest redraws.
- **151 glyphs adapted from licensed fonts**: 98 Charis/Gentium-based reconstructions, the 51-character supplement, and two new Charis-based adaptations (U+208F and U+A7F1).

Adapted glyphs retain their upstream attribution.

## 0.601 changes

Adds 15 audited phonetic/transcription characters and 26 circled capitals. U+208F and U+A7F1 use smooth Charis-based adaptations; no Unifont outlines were added. Fixes enclosed ring/caron positioning, including normalized precomposed inputs. [Actual-font comparison images](https://github.com/ghehyoein/IPAplus-keyboard-ios/tree/main/Font/previews/0.601). Local font validation uses HarfBuzz/Pillow; iOS CoreText validation remains separate.
