ipa+ — App-bundled font sources

This pipeline's bundled edition integrates Charis 7.000, Gentium 7.000, BabelStone Roman 16.000, and GNU Unifont / Unifont Upper 18.0.01. Contributions by ghehyoein comprise 51 supplementary glyphs adapted from licensed Charis/Gentium components.

All donor fonts are used under SIL Open Font License 1.1, including the compiled Unifont fonts' OFL option. Adapted glyphs retain upstream attribution.
